## 준비물과 회로도

아두이노 Uno, USB 데이터 케이블, 브레드보드, 점퍼선, 조도센서(LDR), 10kΩ 저항, LED, LED용 330Ω 저항, 10kΩ 가변저항을 준비합니다. 2번 과제만 실습한다면 조도센서와 LED 부품은 필요하지 않습니다.

![1번 조도센서·LED 회로와 2번 가변저항 회로의 스케매틱 다이어그램](/physical_media/week9_serial_circuits.svg)

1번과 2번은 각각 다른 회로입니다. 입력이 모두 A5를 사용하므로 실습을 바꿀 때 조도센서와 가변저항을 동시에 A5에 연결하지 않습니다. 회로를 바꿀 때는 USB를 분리합니다.

## 1번: 강의자료 예제 실행

> PPT의 예제를 실행하라.

조도센서 값을 A5에서 읽어 LED 밝기를 조절하고, 같은 값을 USB 시리얼 통신으로 Processing에 보냅니다. 강의자료의 동작을 유지하면서 별도 폰트 파일 없이 실행할 수 있도록 정리한 코드입니다.

### 회로 연결

아래는 PPT 예제의 브레드보드 연결 이미지입니다.

![PPT 예제: 아두이노 Uno의 A5 조도센서 입력과 D6 LED 출력을 연결한 회로](/physical_media/week9_ppt_circuit.png)

LED에는 전류 제한용 330Ω 저항을 직렬로 추가해 연결합니다. 위 스케매틱 다이어그램에서 LED 저항 위치를 확인하세요.

- `5V → 조도센서 → A5 → 10kΩ 저항 → GND`로 연결합니다. A5는 조도센서와 저항 사이의 접점에 연결합니다.
- `D6 → 330Ω 저항 → LED 애노드(+)`, `LED 캐소드(-) → GND`로 연결합니다.
- 아두이노를 USB 데이터 케이블로 컴퓨터에 연결합니다.

### Arduino 코드

새 스케치에 다음 코드를 넣고 Uno에 업로드합니다. `analogRead()`의 `0~1023` 값을 PWM 출력 범위인 `0~255`로 바꿉니다.

```arduino
const int sensorPin = A5;
const int ledPin = 6;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int sensorValue = analogRead(sensorPin);
  int brightness = map(sensorValue, 0, 1023, 0, 255);

  analogWrite(ledPin, brightness);
  Serial.println(sensorValue);
  delay(50);
}
```

### Processing 코드

[Processing](https://processing.org/download)을 열고 Java 모드의 새 스케치에 넣습니다. `PORT_INDEX` 선택 방법은 아래 실행 순서를 참고하세요.

```java
import processing.serial.*;

Serial arduino;
final int PORT_INDEX = 0;  // 콘솔 목록에서 Arduino 포트 번호로 변경
volatile int sensorValue = 0;

void setup() {
  size(600, 400);
  textSize(28);
  String[] ports = Serial.list();
  printArray(ports);

  if (PORT_INDEX < 0 || PORT_INDEX >= ports.length) {
    println("Check the Arduino connection and PORT_INDEX.");
    exit();
    return;
  }

  arduino = new Serial(this, ports[PORT_INDEX], 9600);
  arduino.clear();
  arduino.bufferUntil('\n');
}

void draw() {
  background(25);
  fill(255);
  text("Light level: " + sensorValue, 35, height / 2);
}

void serialEvent(Serial port) {
  String line = port.readStringUntil('\n');
  if (line == null) return;
  line = trim(line);
  if (!line.matches("[0-9]{1,4}")) return;

  int value = Integer.parseInt(line);
  if (value >= 0 && value <= 1023) {
    sensorValue = value;
  }
}
```

조도센서를 손으로 가렸다가 빛을 비추면 화면의 숫자와 LED 밝기가 함께 바뀌어야 합니다.

## 2번: 가변저항으로 원 크기 조절하기

> 가변저항과 원을 제작하라. 왼쪽으로 돌리면 원이 작아지고, 오른쪽으로 돌리면 원이 커지도록 한다.

### 회로 연결

1. 가변저항의 가운데 단자(와이퍼)를 `A5`에 연결합니다.
2. 양 끝 단자를 각각 `5V`, `GND`에 연결합니다.
3. Uno를 컴퓨터에 USB로 연결합니다. 이 실습에는 LED가 필요하지 않습니다.

가변저항은 보는 방향과 배선에 따라 값이 증가하는 회전 방향이 달라집니다. 오른쪽으로 돌릴 때 값이 증가하도록 배선하고, 반대라면 USB를 분리한 뒤 양 끝의 5V·GND 연결을 서로 바꾸세요. 가운데 A5 연결은 유지합니다.

### Arduino 코드

1번 코드를 다음 코드로 교체하여 업로드합니다. 숫자 하나와 줄바꿈만 전송해야 아래 Processing 코드가 읽을 수 있습니다.

```arduino
const int potPin = A5;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int potValue = analogRead(potPin);
  Serial.println(potValue);
  delay(20);
}
```

### Processing 코드

Processing에 별도의 새 스케치를 만들어 아래 코드를 넣습니다. 수신값 `0~1023`을 원의 지름 `20~360`픽셀로 변환합니다.

```java
import processing.serial.*;

Serial arduino;
final int PORT_INDEX = 0;  // 콘솔 목록에서 Arduino 포트 번호로 변경
volatile int potValue = 0;

void setup() {
  size(600, 500);
  textSize(20);
  String[] ports = Serial.list();
  printArray(ports);

  if (PORT_INDEX < 0 || PORT_INDEX >= ports.length) {
    println("Check the Arduino connection and PORT_INDEX.");
    exit();
    return;
  }

  arduino = new Serial(this, ports[PORT_INDEX], 9600);
  arduino.clear();
  arduino.bufferUntil('\n');
}

void draw() {
  int value = potValue;
  float diameter = map(value, 0, 1023, 20, 360);

  background(25);
  noStroke();
  fill(255, 190, 65);
  ellipse(width / 2, height / 2, diameter, diameter);

  fill(255);
  text("Sensor: " + value, 20, 30);
  text("Diameter: " + int(diameter) + " px", 20, height - 20);
}

void serialEvent(Serial port) {
  String line = port.readStringUntil('\n');
  if (line == null) return;
  line = trim(line);
  if (!line.matches("[0-9]{1,4}")) return;

  int value = Integer.parseInt(line);
  if (value >= 0 && value <= 1023) {
    potValue = value;
  }
}
```

### 실행 순서와 포트 선택

1. Arduino IDE에서 보드와 포트를 선택하고 Arduino 코드를 업로드합니다.
2. Arduino IDE의 시리얼 모니터와 시리얼 플로터를 닫습니다.
3. Processing 코드를 실행하면 콘솔에 `[0]`, `[1]` 같은 번호와 포트 이름이 출력됩니다.
4. Arduino IDE에서 확인한 포트와 같은 항목을 찾아 `PORT_INDEX`를 해당 번호로 수정합니다. 예를 들어 `[2]`가 아두이노이면 `PORT_INDEX = 2`로 설정합니다.
5. Processing 실행 창을 종료한 뒤 다시 실행합니다. macOS의 `/dev/cu.usbmodem...`, `/dev/cu.usbserial...`, Windows의 `COM3` 같은 이름은 환경마다 다릅니다.
6. 왼쪽 끝에서는 작은 원, 오른쪽 끝에서는 큰 원이 나타나는지 확인합니다. 포트를 점유하는 다른 Processing 창도 모두 닫아야 합니다.

포트가 안 보이면 USB 케이블이 데이터 전송을 지원하는지 확인합니다. `Port busy` 또는 `Access denied`가 나오면 시리얼 모니터나 다른 프로그램이 포트를 사용 중인지 확인하세요. 두 코드의 통신 속도는 모두 `9600`으로 맞춥니다.
