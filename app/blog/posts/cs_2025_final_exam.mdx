### 10번. 덧셈 프로그램 빈칸

`sum = num + 10`을 계산해 출력하는 프로그램입니다.

```asm
        BR      main
num:    .BLOCK  2
sum:    .BLOCK  2
bonus:  .EQUATE 10          ; (1) 상수 10 정의
msg:    .ASCII  "enter a number: \x00"
main:   STRO    msg, d
        DECI    num, d
        LDA     num, d
        ADDA    bonus, i
        STA     sum, d      ; (2) 더한 결과를 sum에 저장
        DECO    sum, d      ; (3) 결과를 10진수로 출력
        STOP
        .END
```

- 빈칸 정답: **`bonus: .EQUATE 10`**, **`STA sum, d`**, **`DECO sum, d`**

### 11번. While 루프 빈칸

0이 입력될 때까지 입력값을 누적(`sum += input`)하는 프로그램입니다.

```asm
        BR      main
input:  .BLOCK  2
sum:    .BLOCK  2
msg1:   .ASCII  "enter numbers(0: quit): \x00"
msg2:   .ASCII  "sum: \x00"
main:   STRO    msg1, d
while:  DECI    input, d
        LDA     input, d    ; (1) 비교를 위해 input 로드
        CPA     0, i
        BREQ    endWhile    ; (2) input == 0 이면 루프 탈출
        ADDA    sum, d
        STA     sum, d
        BR      while       ; (3) 루프 처음으로 복귀
endWhile: STRO  msg2, d
        DECO    sum, d
        STOP
        .END
```

- 빈칸 정답: **`LDA input, d`**, **`BREQ endWhile`**, **`BR while`**

### 12번. 대문자 판별(IF 조건문) 빈칸

`if (ch >= 'A' && ch <= 'Z')` 를 두 단계 비교로 구현합니다.

```asm
        BR      main
ch:     .BLOCK  1
main:   CHARI   ch, d
if:     LDA     0x0000, i
        LDBYTEA ch, d
        CPA     'A', i
        BRLT    else        ; ch < 'A' 이면 else
        LDBYTEA ch, d       ; (1) ch 값을 다시 로드
        CPA     'Z', i      ; (2) 'Z'와 비교
        BRGT    else        ; (3) ch > 'Z' 이면 else
        STRO    msg1, d
        BR      endIf
else:   STRO    msg2, d
endIf:  STOP
msg1:   .ASCII  "Capital Letter\x00"
msg2:   .ASCII  "Not Capital Letter\x00"
        .END
```

- 빈칸 정답: **`LDBYTEA ch, d`**, **`CPA 'Z', i`**, **`BRGT else`**

### 8번. 코드 해독 (출력값: `2`)

이 문제의 핵심은 **자기수정코드(self-modifying code)** 입니다. 실행 중에 명령어 자신을 바꿔버립니다.

**실행 추적**

```asm
D1 00 1D   ; LDBYTEA 0x001D,d → A의 하위바이트 = 0x81
F1 00 09   ; STBYTEA 0x0009,d → 0x0009의 71(ADDA)을 81(SUBA)로 덮어씀!
C1 00 17   ; LDA 0x0017,d → A = 5
71 00 19   ; ↑에서 81로 바뀜 → 실제로는 SUBA 0x0019,d → A = 5 - 3 = 2
A1 00 1B   ; ORA 0x001B,d → A = 2 OR 0x30 = 0x32 ('2')
F1 00 16   ; STBYTEA 0x0016,d → 0x0016에 0x32 저장
51 00 16   ; CHARO 0x0016,d → '2' 출력
00         ; STOP
```

- `81`을 0x0009에 써넣어 `ADDA(71)`가 `SUBA(81)`로 바뀝니다 → `5 + 3`이 아니라 **`5 - 3 = 2`**.
- 2를 0x30과 OR 연산하면 0x32 = 문자 **`'2'`** → 최종 **출력값은 `2`**.

### 9번. % 연산 아이디어

`number % 2 == 0`은 짝수 판별입니다. **2진수에서 짝수/홀수는 최하위 비트(LSB) 하나로 결정**됩니다.

```asm
        LDA     number, d
        ANDA    1, i         ; 최하위 비트만 남김 (number & 1)
        BREQ    even         ; 결과가 0이면 짝수 → 분기
        ; 결과가 1이면 홀수
```

- `ANDA 1, i` 결과가 **0이면 짝수**, **1이면 홀수**임을 이용해 `BREQ`(또는 `BRNE`)로 분기하면 됩니다.
