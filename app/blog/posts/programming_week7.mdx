## 연습 문제(6)

**주제:** 미니 인터프리터 만들기 (Punchy)

본 실습은 입력된 가상 명령어(Opcode)에 따라 변수 값을 조작하는 판별 로직을 작성하고, 연속적인 명령어 스트림을 다루는 **루프 제어 구조**를 이해하는 것을 목표로 합니다.

프로그램에는 오직 두 개의 정수형 변수 `A`와 `B`만 존재하며, 최초 값은 둘 다 **0**입니다. 명령어는 **1부터 7까지**의 숫자로 시작합니다.

### 1단계: 단일 명령어 처리 및 출력 (변수, 입출력, 조건문)

**설명:** 명령어 1번(값 대입)과 2번(값 출력)의 기본 동작을 구현합니다.

**제한 사항**

- 한 번의 명령만 입력받고 바로 종료되도록 작성합니다.
- `char`형 변수 하나를 입력받아 `'A'`이면 변수 `A`를, `'B'`이면 변수 `B`를 대상으로 연산합니다.

**출력 예시**

```text
명령어를 입력하세요: 1 A 25
(A에 25가 저장됨, 프로그램 종료)

명령어를 입력하세요: 2 A
(A의 값을 출력)
```

<RevealAnswer title="1단계 정답 보기 (클릭하여 펼침)">

```cpp
#include <iostream>
using namespace std;

int main() {
    // 이 프로그램이 다루는 유일한 두 변수, 0으로 초기화
    int A = 0;
    int B = 0;

    int cmd;        // 명령어 번호 (1~7)
    char targetX;   // 대상 변수 이름 ('A' 또는 'B')
    int valueN;     // 대입할 정수 값

    cout << "명령어를 입력하세요: ";
    cin >> cmd;     // 먼저 명령어 번호만 읽는다

    if (cmd == 1) {                 // 1번: 변수에 값 대입
        cin >> targetX >> valueN;   // 대상 변수와 값을 이어서 받기
        if (targetX == 'A') {
            A = valueN;
        } else if (targetX == 'B') {
            B = valueN;
        }
    } else if (cmd == 2) {          // 2번: 변수 값 출력
        cin >> targetX;             // 출력할 대상 변수만 받기
        if (targetX == 'A') {
            cout << A << endl;
        } else if (targetX == 'B') {
            cout << B << endl;
        }
    }

    return 0;
}
```

`cin >>`은 공백을 자동으로 건너뛰므로 `cmd`를 먼저 읽고, 명령이 1번이면 `cin >> targetX >> valueN`으로 나머지를 이어 받습니다.

</RevealAnswer>

### 2단계: 7번 명령어가 나올 때까지 무한 실행 (반복문 제어)

**설명:** 사용자가 7번(종료) 명령어를 입력할 때까지 계속해서 다음 명령어를 입력받아 실행하는 루프를 구성합니다.

**제한 사항**

- `while (true)` 루프를 사용하고, 명령어 종류가 **7일 때 `break`**로 루프를 탈출합니다.
- 1단계에서 만든 1번·2번 기능이 루프 안에서 누적되어 동작해야 합니다.

**출력 예시**

```text
1 A 15
1 B 40
2 A
15
2 B
40
7
(프로그램 종료)
```

```cpp
                cout << A << endl;
            } else if (targetX == 'B') {
                cout << B << endl;
            }
        }
    }
```

### 3단계: 기본 사칙연산 명령어 추가 (복합 조건문, 누적 연산자)

**설명:** 두 변수 간의 덧셈·곱셈·뺄셈을 수행하는 명령어 3, 4, 5번 기능을 추가합니다.

**제한 사항**

- `3 X Y`: `X += Y` (X에 Y를 더해 다시 X에 저장)
- `4 X Y`: `X *= Y`
- `5 X Y`: `X -= Y`

**출력 예시**

```text
1 A 5
1 B 3
3 A B   (A = 5 + 3 = 8)
2 A
8
4 B A   (B = 3 * 8 = 24)
2 B
24
7
```

<RevealAnswer title="3단계 정답 보기 (클릭하여 펼침)">

```cpp
#include <iostream>
using namespace std;

int main() {
    int A = 0;  // 프로그램이 관리하는 변수 A
    int B = 0;  // 프로그램이 관리하는 변수 B

    int cmd;        // 명령어 번호 (1~7)
    char targetX, targetY;  // 사칙연산은 대상 변수 두 개(X, Y)가 필요
    int valueN;     // 1번 명령에서 대입할 정수 값

    while (true) {          // 종료 명령이 들어올 때까지 무한 반복
        cin >> cmd;         // 매 반복마다 새 명령어 번호를 읽는다

        if (cmd == 7) {     // 7번: 프로그램 종료
            break;
        }

        if (cmd == 1) {                 // 1번: 값 대입
            cin >> targetX >> valueN;
            if (targetX == 'A') {
                A = valueN;
            } else if (targetX == 'B') {
                B = valueN;
            }
        } else if (cmd == 2) {          // 2번: 값 출력
            cin >> targetX;
            if (targetX == 'A') {
                cout << A << endl;
            } else if (targetX == 'B') {
                cout << B << endl;
            }
        } else if (cmd == 3) {              // 3번: 덧셈 (X += Y)
            cin >> targetX >> targetY;      // 연산에 쓸 변수 이름 두 개 받기
            if (targetX == 'A') {
                if (targetY == 'A') {
                    A = A + A;
                } else {
                    A = A + B;
                }
            } else {
                if (targetY == 'A') {
                    B = B + A;
                } else {
                    B = B + B;
                }
            }
        } else if (cmd == 4) {              // 4번: 곱셈 (X *= Y)
            cin >> targetX >> targetY;
            if (targetX == 'A') {
                if (targetY == 'A') {
                    A = A * A;
                } else {
                    A = A * B;
                }
            } else {
                if (targetY == 'A') {
                    B = B * A;
                } else {
                    B = B * B;
                }
            }
        } else if (cmd == 5) {              // 5번: 뺄셈 (X -= Y)
            cin >> targetX >> targetY;
            if (targetX == 'A') {
                if (targetY == 'A') {
                    A = A - A;
                } else {
                    A = A - B;
                }
            } else {
                if (targetY == 'A') {
                    B = B - A;
                } else {
                    B = B - B;
                }
            }
        }
    }

    return 0;
}
```

명령어 3·4·5번을 각각의 `else if` 가지로 분리했습니다. `targetX`가 `'A'`인지 먼저 나눈 뒤, 그 안에서 `targetY`에 따라 연산합니다.

### 4단계: 정수 나눗셈 처리 및 에러 검사 (논리 연산자, 예외 처리)

**설명:** 몫만 취하는 정수 나눗셈 명령어 6번을 추가하고, 조건문으로 **0으로 나누기**(Division by Zero) 예외를 방지합니다.

**제한 사항**

- `6 X Y`: X를 Y로 나눈 **몫**을 X에 저장합니다 (`X /= Y`).
- 나누는 수인 Y의 값이 **0이면** `에러: 0으로 나눌 수 없습니다!`를 출력하고 연산을 수행하지 마세요.

**출력 예시**

```text
1 A 7
1 B 2
6 A B   (A = 7 / 2 = 3, 나머지 버림)
2 A
3
1 B 0
6 A B
에러: 0으로 나눌 수 없습니다!
7
```

<RevealAnswer title="4단계 정답 보기 (클릭하여 펼침)">

```cpp
#include <iostream>
using namespace std;

int main() {
    int A = 0;  // 프로그램이 관리하는 변수 A
    int B = 0;  // 프로그램이 관리하는 변수 B

    int cmd;        // 명령어 번호 (1~7)
    char targetX, targetY;  // 사칙연산·나눗셈에 쓰는 변수 이름
    int valueN;     // 1번 명령에서 대입할 정수 값

    while (true) {          // 종료 명령이 들어올 때까지 무한 반복
        cin >> cmd;         // 매 반복마다 새 명령어 번호를 읽는다

        if (cmd == 7) {     // 7번: 프로그램 종료
            break;
        }

        if (cmd == 1) {                 // 1번: 값 대입
            cin >> targetX >> valueN;
            if (targetX == 'A') {
                A = valueN;
            } else if (targetX == 'B') {
                B = valueN;
            }
        } else if (cmd == 2) {          // 2번: 값 출력
            cin >> targetX;
            if (targetX == 'A') {
                cout << A << endl;
            } else if (targetX == 'B') {
                cout << B << endl;
            }
        } else if (cmd == 3) {              // 3번: 덧셈 (X += Y)
            cin >> targetX >> targetY;
            if (targetX == 'A') {
                if (targetY == 'A') {
                    A = A + A;
                } else {
                    A = A + B;
                }
            } else {
                if (targetY == 'A') {
                    B = B + A;
                } else {
                    B = B + B;
                }
            }
        } else if (cmd == 4) {              // 4번: 곱셈 (X *= Y)
            cin >> targetX >> targetY;
            if (targetX == 'A') {
                if (targetY == 'A') {
                    A = A * A;
                } else {
                    A = A * B;
                }
            } else {
                if (targetY == 'A') {
                    B = B * A;
                } else {
                    B = B * B;
                }
            }
        } else if (cmd == 5) {              // 5번: 뺄셈 (X -= Y)
            cin >> targetX >> targetY;
            if (targetX == 'A') {
                if (targetY == 'A') {
                    A = A - A;
                } else {
                    A = A - B;
                }
            } else {
                if (targetY == 'A') {
                    B = B - A;
                } else {
                    B = B - B;
                }
            }
        } else if (cmd == 6) {              // 6번: 정수 나눗셈 (X /= Y)
            cin >> targetX >> targetY;
            if (targetX == 'A') {
                if (targetY == 'A') {
                    if (A == 0) {
                        cout << "에러: 0으로 나눌 수 없습니다!" << endl;
                    } else {
                        A = A / A;
                    }
                } else {
                    if (B == 0) {
                        cout << "에러: 0으로 나눌 수 없습니다!" << endl;
                    } else {
                        A = A / B;
                    }
                }
            } else {
                if (targetY == 'A') {
                    if (A == 0) {
                        cout << "에러: 0으로 나눌 수 없습니다!" << endl;
                    } else {
                        B = B / A;
                    }
                } else {

                        cout << "에러: 0으로 나눌 수 없습니다!" << endl;

            }
```

### 5단계: 실행 제어 함수화 및 최종 통계 (함수 구조화)

```cpp
#include <iostream>
using namespace std;

// A, B는 함수 안에서 직접 값을 바꿔야 하므로 전역 변수로 선언
int A = 0;
int B = 0;

// 명령어 한 개를 해석해서 A 또는 B의 값을 조작하는 핵심 함수
void executeCommand(int cmd, char targetX, char targetY, int value) {
    if (cmd == 1) {                     // 1번: 값 대입
        if (targetX == 'A') {
            A = value;
        } else {
            B = value;
        }
    } else if (cmd == 2) {              // 2번: 값 출력
        if (targetX == 'A') {
            cout << A << endl;
        } else {
            cout << B << endl;
        }
    } else if (cmd == 3) {              // 3번: 덧셈 (X += Y)
        if (targetX == 'A') {
            if (targetY == 'A') {
                A = A + A;
            } else {
                A = A + B;
            }
        } else {
            if (targetY == 'A') {
                B = B + A;
            } else {
                B = B + B;
            }
        }
    } else if (cmd == 4) {              // 4번: 곱셈 (X *= Y)
        if (targetX == 'A') {
            if (targetY == 'A') {
                A = A * A;
            } else {
                A = A * B;
            }
        } else {
            if (targetY == 'A') {
                B = B * A;
            } else {
                B = B * B;
            }
        }
    } else if (cmd == 5) {              // 5번: 뺄셈 (X -= Y)
        if (targetX == 'A') {
            if (targetY == 'A') {
                A = A - A;
            } else {
                A = A - B;
            }
        } else {
            if (targetY == 'A') {
                B = B - A;
            } else {
                B = B - B;
            }
        }
    } else if (cmd == 6) {              // 6번: 정수 나눗셈 (X /= Y)
        if (targetX == 'A') {
            if (targetY == 'A') {
                if (A == 0) {
                    cout << "에러: 0으로 나눌 수 없습니다!" << endl;
                } else {
                    A = A / A;
                }
            } else {
                if (B == 0) {
                    cout << "에러: 0으로 나눌 수 없습니다!" << endl;
                } else {
                    A = A / B;
                }
            }
        } else {
            if (targetY == 'A') {
                if (A == 0) {
                    cout << "에러: 0으로 나눌 수 없습니다!" << endl;
                } else {
                    B = B / A;
                }
            } else {
                if (B == 0) {
                    cout << "에러: 0으로 나눌 수 없습니다!" << endl;
                } else {
                    B = B / B;
                }
            }
        }
    }
}

int main() {
    int cmd;                        // 명령어 번호 (1~7)
    char targetX = ' ', targetY = ' ';  // 명령에 따라 사용할 변수 이름
    int value = 0;                  // 1번 명령에서 대입할 정수 값
    int execCount = 0;              // 실행된 유효 명령어 개수 누적

    while (true) {                  // 종료 명령이 들어올 때까지 반복
        cin >> cmd;                 // 매 반복마다 명령어 번호를 먼저 읽는다

        if (cmd == 7) {             // 7번: 종료
            break;                  // 루프 탈출 (통계 출력은 아래에서)
        }

        // 명령 번호에 따라 필요한 인자만큼만 이어서 입력받기
        if (cmd == 1) {
            cin >> targetX >> value;    // 대상 변수 + 값
        } else if (cmd == 2) {
            cin >> targetX;             // 대상 변수만
        } else {
            cin >> targetX >> targetY;  // 3~6번: 대상 변수 두 개
        }

        executeCommand(cmd, targetX, targetY, value);   // 실제 연산은 함수에 위임
        execCount++;                                    // 종료 명령(7)은 제외하고 +1
    }

    // 종료 시 통계 출력
    cout << "====================================" << endl;
    cout << "[인터프리터 시스템 종료]" << endl;
    cout << "- 총 실행된 유효 명령어: " << execCount << "회 (종료 명령 제외)" << endl;
    cout << "====================================" << endl;

    return 0;
}
```
