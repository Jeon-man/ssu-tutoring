## 연습 문제(4)

**주제:** 간단한 계산기

**교재:** [UniBook — 연습 문제(4) 간단한 계산기](https://unibook.co/book/15/section/1396)

두 개의 숫자와 연산자(`+ - * /`)를 입력받아 계산 결과를 알려 주는 프로그램입니다. 아래 **1단계 → 4단계** 순서로 코드를 쌓아 가세요. 각 단계를 먼저 직접 작성해 보고, 막히면 **정답 보기**를 펼쳐 보세요.

> **참고.** 연산자는 `char op;`로 한 글자만 입력받고, `if (op == '+')`처럼 비교합니다.

---

### 1단계: 사칙연산 계산하기 (변수, 입출력, 조건문)

**목표:** 두 수와 연산자를 입력받아 알맞은 사칙연산 결과를 출력합니다.

**요구사항**

- 두 실수 `a`, `b`와 연산자 `op`를 입력받으세요.
- 연산자가 `+`, `-`, `*`, `/`일 때 각각의 결과를 출력하세요.

<RevealAnswer title="1단계 정답 보기 (클릭하여 펼침)">

```cpp
#include <iostream>
using namespace std;

int main() {
    double a, b;
    char op;

    cout << "첫 번째 숫자: ";
    cin >> a;
    cout << "연산자(+ - * /): ";
    cin >> op;
    cout << "두 번째 숫자: ";
    cin >> b;

    if (op == '+') {
        cout << "결과: " << a + b << endl;
    } else if (op == '-') {
        cout << "결과: " << a - b << endl;
    } else if (op == '*') {
        cout << "결과: " << a * b << endl;
    } else if (op == '/') {
        cout << "결과: " << a / b << endl;
    }

    return 0;
}
```

`op`에 담긴 연산자에 따라 알맞은 분기 하나만 실행됩니다.

</RevealAnswer>

### 2단계: 잘못된 입력 처리하기 (복합 조건문, 논리 연산자)

**목표:** **0으로 나누기**와 **이상한 연산자**를 걸러냅니다.

**요구사항**

- 연산자가 `/`이고 `b`가 **0**이면 `0으로 나눌 수 없습니다!`를 출력하세요.
- `+ - * /` 중 어느 것도 아니면 `잘못된 연산자입니다!`를 출력하세요. (`else` 활용)

<RevealAnswer title="2단계 정답 보기 (클릭하여 펼침)">

```cpp
#include <iostream>
using namespace std;

int main() {
    double a, b;
    char op;

    cout << "첫 번째 숫자: ";
    cin >> a;
    cout << "연산자(+ - * /): ";
    cin >> op;
    cout << "두 번째 숫자: ";
    cin >> b;

    if (op == '+') {
        cout << "결과: " << a + b << endl;
    } else if (op == '-') {
        cout << "결과: " << a - b << endl;
    } else if (op == '*') {
        cout << "결과: " << a * b << endl;
    } else if (op == '/') {
        if (b == 0) {
            cout << "0으로 나눌 수 없습니다!" << endl;
        } else {
            cout << "결과: " << a / b << endl;
        }
    } else {
        cout << "잘못된 연산자입니다!" << endl;
    }

    return 0;
}
```

나눗셈은 `b == 0`인지 한 번 더 확인하고, 어떤 연산자에도 해당하지 않으면 마지막 `else`로 걸러냅니다.

</RevealAnswer>

### 3단계: 여러 번 계산하기 (반복문)

**목표:** 계산을 한 번만 하지 않고, 사용자가 **그만둘 때까지** 반복합니다.

**요구사항**

- `while` 반복문으로 계산을 반복하세요.
- 연산자로 `q`를 입력하면 `계산기를 종료합니다.`를 출력하고 반복을 끝내세요. (`break` 활용)

<RevealAnswer title="3단계 정답 보기 (클릭하여 펼침)">

```cpp
#include <iostream>
using namespace std;

int main() {
    double a, b;
    char op;

    while (true) {
        cout << "연산자(+ - * /, 종료는 q): ";
        cin >> op;

        if (op == 'q') {
            cout << "계산기를 종료합니다." << endl;
            break;
        }

        cout << "첫 번째 숫자: ";
        cin >> a;
        cout << "두 번째 숫자: ";
        cin >> b;

        if (op == '+') {
            cout << "결과: " << a + b << endl;
        } else if (op == '-') {
            cout << "결과: " << a - b << endl;
        } else if (op == '*') {
            cout << "결과: " << a * b << endl;
        } else if (op == '/') {
            if (b == 0) {
                cout << "0으로 나눌 수 없습니다!" << endl;
            } else {
                cout << "결과: " << a / b << endl;
            }
        } else {
            cout << "잘못된 연산자입니다!" << endl;
        }
    }

    return 0;
}
```

`q`를 먼저 검사해서 종료하고, 그 외에는 숫자를 입력받아 계산을 이어 갑니다.

</RevealAnswer>

### 4단계: 기능을 함수로 분리하기 (함수 구조화)

**목표:** `main`의 코드를 정리하고, 기능을 **함수 단위**로 나눕니다.

**요구사항**

다음 세 가지 함수를 정의하고 `main`에서 호출하세요.

<table>
  <thead>
    <tr>
      <th scope="col">함수</th>
      <th scope="col">역할</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>void printMenu()</code></td>
      <td>사용할 수 있는 연산자 안내 문구 출력</td>
    </tr>
    <tr>
      <td><code>bool isValidOperator(char op)</code></td>
      <td>
        <code>op</code>가 <code>+ - * /</code> 중 하나면 <code>true</code>, 아니면 <code>false</code> 반환
      </td>
    </tr>
    <tr>
      <td><code>double calculate(double a, double b, char op)</code></td>
      <td>연산자에 맞는 계산 결과를 반환</td>
    </tr>
  </tbody>
</table>

<RevealAnswer title="4단계 정답 보기 (클릭하여 펼침)">

```cpp
#include <iostream>
using namespace std;

void printMenu() {
    cout << "=== 간단한 계산기 ===" << endl;
    cout << "사용 가능한 연산자: + - * / (종료는 q)" << endl;
}

bool isValidOperator(char op) {
    return op == '+' || op == '-' || op == '*' || op == '/';
}

double calculate(double a, double b, char op) {
    if (op == '+') return a + b;
    if (op == '-') return a - b;
    if (op == '*') return a * b;
    return a / b;
}

int main() {
    double a, b;
    char op;

    printMenu();

    while (true) {
        cout << "연산자: ";
        cin >> op;

        if (op == 'q') {
            cout << "계산기를 종료합니다." << endl;
            break;
        }

        if (!isValidOperator(op)) {
            cout << "잘못된 연산자입니다!" << endl;
            continue;
        }

        cout << "첫 번째 숫자: ";
        cin >> a;
        cout << "두 번째 숫자: ";
        cin >> b;

        if (op == '/' && b == 0) {
            cout << "0으로 나눌 수 없습니다!" << endl;
            continue;
        }

        cout << "결과: " << calculate(a, b, op) << endl;
    }

    return 0;
}
```

안내(`printMenu`)·유효성 검사(`isValidOperator`)·계산(`calculate`)을 함수로 나누면, `main`에는 “입력받아 검사하고 계산한다”는 흐름만 남아 훨씬 읽기 쉬워집니다.

</RevealAnswer>
