## Part 1. 개념 이해

### 문제 1 — 컴퓨팅적 사고

다음 중 컴퓨팅적 사고(Computational Thinking)를 **가장 잘** 설명한 것은?

1. 딥러닝을 문제에 적용하여 최적의 답을 찾는 것
2. 어플리케이션(SW)를 효율적으로 개발하는 노하우
3. 문제 해결을 위해 컴퓨터 과학 분야의 개념을 적용하는 사고 방식
4. 수학적, 통계적 영역의 문제를 해결하는 프로그래밍 기법

<RevealAnswer title="정답 및 해설 (클릭하여 펼침)">

**정답:** 3번

**해설:** 컴퓨팅적 사고는 딥러닝·통계 기법만이 아니라, **분해·패턴 인식·알고리즘·자동화** 같은 컴퓨터 과학 개념으로 문제를 푸는 **일반적인 사고 방식**이다. 1번은 AI에 한정되고, 2번은 개발 노하우, 4번은 수학·통계 프로그래밍에 가깝다.

</RevealAnswer>

### 문제 2 — 분해(Decomposition)

컴퓨팅적 사고 방식의 핵심 개념 중 **「복잡한 문제를 작은 문제로 나누어 해결하는 방식」**을 의미하는 것은?

1. 분해(Decomposition)
2. 알고리즘(Algorithm)
3. 자동화(Automation)
4. 패턴 인식(Pattern Recognition)
5. 객체(Object)

<RevealAnswer title="정답 및 해설 (클릭하여 펼침)">

**정답:** 1번 — 분해(Decomposition)

**해설:** 큰 문제를 **작은 단위로 쪼개** 차례로 해결하는 것이 분해다. 2번 알고리즘은 해결 **절차**, 3번 자동화는 반복 작업 위임, 4번 패턴 인식은 규칙 찾기, 5번 객체는 프로그래밍 용어로 다른 개념이다.

</RevealAnswer>

### 문제 3 — 지넷 윙

컴퓨팅적 사고 교육을 강조하고 전 세계에 확산시킨 사람은?

1. 지넷 윙
2. 빌 게이츠
3. 스티브 잡스
4. 귀도 반 로섬
5. 앨런 튜링

**정답:** 1번 — 지넷 윙(Jeannette Wing)

**해설:** 컬럼비아대 지넷 윙 교수가 컴퓨팅적 사고 교육의 중요성을 널리 알렸다. 빌 게이츠·스티브 잡스는 IT 기업인, 귀도 반 로섬은 파이썬 창시자, 앨런 튜링은 컴퓨터 과학 선구자이나 ‘컴퓨팅적 사고 확산’과 직접 연결되는 정답은 지넷 윙이다.

</RevealAnswer>

1. 파이썬은 고급 언어(High Level Language)이다.

</RevealAnswer>

### 문제 4 — 에러 코드 (2개)

다음 중 **에러가 발생하는** 것을 모두 고르시오. **(2개)**

1. `a = 10`
2. `a + 10 = 20`
3. `20 = x`
4. `x == 20`
5. `b = 10 // 2`

<RevealAnswer title="정답 및 해설 (클릭하여 펼침)">

**정답:** 2번, 3번

**해설:** 대입은 **왼쪽이 변수**여야 한다. `a + 10 = 20`은 연산 결과에 대입할 수 없고, `20 = x`는 상수에 대입할 수 없다. `a = 10`, `x == 20`(비교), `b = 10 // 2`는 문법상 문제 없다.

</RevealAnswer>

### 문제 5-1 — 연산 순서

아래 코드를 실행했을 때의 결과를 적으시오.

```python
a = 10
a = a + 10
b = a + 20
print(a)
```

<RevealAnswer title="정답 및 해설 (클릭하여 펼침)">

**정답:** `20`

**해설:** `a = 10` → `a = a + 10`으로 **20**, `b = 40`이 되지만 `print(a)`는 **a만** 출력하므로 **20**이다.

</RevealAnswer>

## Part 3. Turtle 그래픽 코딩

### 문제 1 — `rt(120)` × 3

아래의 코드를 수행했을 때 **어떤 도형**이 그려지는가?

```python
import turtle
turtle.fd(120)
turtle.rt(120)
turtle.fd(120)
turtle.rt(120)
turtle.fd(120)
```

<RevealAnswer title="정답 및 해설 (클릭하여 펼침)">

**정답:** 4번 — 역삼각형

**해설:** 변 3개·매번 **오른쪽 120°**(`rt`)로 꺾이면 삼각형이 완성된다. 시계 방향으로 그리면 **▽ 역삼각형** 형태가 된다.

</RevealAnswer>

---

### 문제 2 — `left(120)` × 5

아래의 코드를 수행했을 때 **어떤 도형**이 그려지는가?

```python
import turtle
import time
for _ in range(5):
    turtle.fd(120)
    turtle.left(120)
    time.sleep(1)
```

<RevealAnswer title="정답 및 해설 (클릭하여 펼침)">

**정답:** 1번 — 정삼각형

**해설:** 한 변 그리고 **왼쪽 120°** 회전을 반복하면 **정삼각형** 한 바퀴가 그려진다. `range(5)`는 5번 반복하지만, 3번이면 삼각형이 닫히고 이후는 같은 도형 위를 다시 그린다.

</RevealAnswer>

---

### 문제 3 — `left(90)` × 5

아래의 코드를 수행했을 때 **어떤 도형**이 그려지는가?

```python
import turtle as t
t.shape('turtle')
t.shapesize(2)
for x in range(5):
    t.foward(90)
    t.left(90)
```

<RevealAnswer title="정답 및 해설 (클릭하여 펼침)">

**정답:** 2번 — 정사각형

**해설:** 90°씩 네 번 꺾이면 **정사각형**이다. 원문은 `foward` 오타이며, 실행할 때는 `forward`로 고쳐야 한다.

</RevealAnswer>

**해설:** Turtle에서 선 **두께**는 `width()`(또는 `pensize()`), **색**은 `color()`로 바꾼다. `setheading`은 방향, 나머지는 이 문제 범위의 공식 함수명이 아니다.

</RevealAnswer>

### 문제 5 — 별 모양

아래 코드를 실행하면 **어떤 그림**이 그려지는지 선택하시오.


<RevealAnswer title="정답 및 해설 (클릭하여 펼침)">

**해설:** 정오각형 별은 **외각 144°**(`right(144)`)로 꼭짓점 5개를 이을 때 그려진다. 5번 반복하면 오각별 모양이 완성된다.

</RevealAnswer>

### 문제 6 — 정팔각형

정팔각형을 그리기 위해 아래 코드에서 밑줄 안에 들어갈 숫자는?

```python
import turtle as t
a = _____
b = a * 2
for x in range(b):
```

</RevealAnswer>

### 문제 3 — 몸무게 입력 (2개)

몸무게(소수점 포함)를 입력받을 때 필요한 함수를 모두 선택하시오. **(2개)**

1. `int`
2. `float`
3. `input`
4. `print`
5. `weight`
