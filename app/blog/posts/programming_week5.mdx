아래의 코드는 `'Python'`을 화면에 **몇 번** 출력하는가?

```python
for a in range(7):
    print('Python')
    if a == 7:
        print('Python')
```

<RevealAnswer title="정답 보기 (클릭하여 펼침)">

**`7`** — `a`는 0~6이므로 `a == 7`은 거짓, 추가 출력 없음

</RevealAnswer>
