## 1번 문제: 서보모터 왕복 회전

> 강의자료의 서보모터를 실험하라.

아두이노 Uno의 4번 핀에 서보모터의 신호선을 연결하고, 서보모터가 `0°`에서 `180°`까지 이동한 뒤 다시 `0°` 방향으로 돌아오도록 작성합니다.

![아두이노 Uno와 서보모터 연결 회로](/physical_media/week8_servo_problem1.png)

```arduino
#include <Servo.h>

Servo myservo;
int pos = 0;

void setup()
{
  myservo.attach(4);
  myservo.write(0);
  delay(500);
}

void loop()
{
  for (pos = 0; pos <= 180; pos += 1)
  {
    myservo.write(pos);
    delay(15);
  }

  delay(1000);

  for (pos = 180; pos >= 0; pos -= 1)
  {
    myservo.write(pos);
    delay(15);
  }

  delay(1000);
}
```

- `myservo.attach(4)`: 서보모터의 제어 신호를 4번 핀에 연결합니다.
- `myservo.write(pos)`: 서보모터의 각도를 지정합니다.
- `delay(15)`: 각도를 조금씩 바꾸는 사이의 시간을 조절해 부드럽게 움직이도록 합니다.

## 2번 문제: 버튼으로 서보모터 각도 조절하기

> DIDO: 버튼 2개를 가지고 실험하자. 버튼 1을 누르면 누를 때마다 0~180도까지 10도씩 증가하여 움직인다. 버튼 2를 누르면 누를 때마다 180에서 0도까지 10도씩 감소하여 움직인다. 0도에 도달하면 노란 LED, 180도에 도달하면 빨간 LED가 켜지도록 한다.

버튼 1(2번 핀)을 누를 때마다 서보모터 각도를 `10°`씩 증가시키고, 버튼 2(3번 핀)를 누를 때마다 `10°`씩 감소시킵니다. 각도가 `0°`이면 노란 LED(13번 핀), `180°`이면 빨간 LED(12번 핀)가 켜지도록 구성합니다.

![버튼 두 개, LED 두 개, 서보모터를 연결한 아두이노 Uno 회로](/physical_media/week8_servo_buttons_problem2.png)

```arduino
#include <Servo.h>

Servo myServo;

const int servoPin = 4;
const int button1Pin = 2;  // 각도 증가 버튼
const int button2Pin = 3;  // 각도 감소 버튼
const int yellowLedPin = 13;
const int redLedPin = 12;

int angle = 0;

const unsigned long debounceMs = 30;
int lastButton1Reading = LOW;
int lastButton2Reading = LOW;
int button1StableState = LOW;
int button2StableState = LOW;
unsigned long button1ChangedAt = 0;
unsigned long button2ChangedAt = 0;

void updateLeds() {
  digitalWrite(yellowLedPin, angle == 0 ? HIGH : LOW);
  digitalWrite(redLedPin, angle == 180 ? HIGH : LOW);
}

void setup() {
  myServo.attach(servoPin);
  myServo.write(angle);

  pinMode(button1Pin, INPUT);
  pinMode(button2Pin, INPUT);

  pinMode(yellowLedPin, OUTPUT);
  pinMode(redLedPin, OUTPUT);

  updateLeds();
}

void loop() {
  const unsigned long now = millis();
  const int reading1 = digitalRead(button1Pin);
  const int reading2 = digitalRead(button2Pin);

  if (reading1 != lastButton1Reading) {
    button1ChangedAt = now;
  }
  if (reading2 != lastButton2Reading) {
    button2ChangedAt = now;
  }

  if (now - button1ChangedAt >= debounceMs && reading1 != button1StableState) {
    button1StableState = reading1;
    if (button1StableState == HIGH) {
      angle = min(angle + 10, 180);
    }
  }

  if (now - button2ChangedAt >= debounceMs && reading2 != button2StableState) {
    button2StableState = reading2;
    if (button2StableState == HIGH) {
      angle = max(angle - 10, 0);
    }
  }

  lastButton1Reading = reading1;
  lastButton2Reading = reading2;
  myServo.write(angle);
  updateLeds();
}
```

이 코드는 외부 풀다운 저항을 사용하는 연결 기준입니다. 각 입력 핀(2번·3번)을 10kΩ 저항으로 GND에 연결하고, 버튼을 누르면 해당 입력 핀이 5V와 연결되도록 합니다. 누르지 않으면 `LOW`, 누르면 `HIGH`입니다. 입력이 30ms 동안 유지된 경우에만 상태 변화를 인정하므로 버튼을 길게 눌러도 한 번에 10도만 움직입니다.

노란 LED는 13번 핀, 빨간 LED는 12번 핀에서 각각 전류 제한 저항(예: 330Ω)을 거쳐 애노드(+)에 연결하고, 캐소드(-)는 GND에 연결합니다. 초기 각도는 0도이므로 처음에는 노란 LED가 켜집니다.

## 3번 문제: 가변저항으로 서보모터 제어하기

> AIDO: 지난주 실험했던 가변저항을 이용하여 가변저항을 돌린 방향과 각도로 서보모터를 똑같이 움직여라.

가변저항의 값을 `A5` 핀에서 읽어 서보모터의 각도로 변환하고, 4번 핀에 연결한 서보모터를 제어합니다.

![가변저항과 서보모터를 연결한 아두이노 Uno 회로](/physical_media/week8_servo_pot_problem3.png)

```arduino
#include <Servo.h>

Servo myServo;

const int potPin = A5;  // 가변저항
const int servoPin = 4; // 서보모터 신호 핀

void setup() {
  myServo.attach(servoPin);
  int initialAngle = map(analogRead(potPin), 0, 1023, 0, 180);
  myServo.write(initialAngle);
}

void loop() {
  int potValue = analogRead(potPin);
  int angle = map(potValue, 0, 1023, 0, 180);

  myServo.write(angle);
  delay(15);
}
```

`analogRead()`로 읽은 `0~1023` 범위의 값을 `map()`으로 `0~180`도 범위로 변환합니다. 가변저항을 돌리면 읽은 값에 따라 서보모터의 목표 각도가 바뀝니다.

가변저항의 가운데 단자는 A5, 양 끝 단자는 5V와 GND에 연결합니다. 회전 방향이 반대로 움직이면 양 끝 단자의 5V와 GND를 서로 바꾸거나, `map(potValue, 0, 1023, 180, 0)`으로 출력 범위를 뒤집습니다.
