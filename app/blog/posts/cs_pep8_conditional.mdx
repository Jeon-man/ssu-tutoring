이번 글에서는 **Pep/8 어셈블리**로 사용자 입력을 받아 조건에 따라 다른 문자열을 출력하는 두 프로그램을 작성합니다. 핵심은 **비교(`CPA`) → 분기(`BRLT`) → 문자열 출력(`STRO`)**의 흐름을 익히는 것입니다.

## 문제 1 — 숫자 1개와 100 비교

**요구사항**

- 숫자 1개를 입력받습니다.
- 그 값이 **100 이상**이면 `greater than or equal to 100`을 출력합니다.
- 그렇지 않으면 `less than 100`을 출력합니다.

**설계 흐름**

1. `DECI`로 숫자를 메모리 `num`에 입력받는다.
2. `LDA`로 `num`을 A에 불러온 뒤 `CPA 100,i`로 100과 비교한다.
3. `num < 100`이면 `BRLT`로 "less" 라벨로 분기, 아니면 그대로 진행하여 "100 이상" 메시지를 출력한다.

<RevealAnswer title="문제 1 정답 보기 (클릭하여 펼침)">

```asm
         BR      main        ; 데이터 영역을 건너뛰고 main으로 점프
num:     .BLOCK  2           ; 입력 숫자를 저장할 변수 (2바이트)
msgGE:   .ASCII  "greater than or equal to 100\x00"
msgLT:   .ASCII  "less than 100\x00"

main:    DECI    num,d       ; 숫자 1개를 입력받아 num에 저장
         LDA     num,d       ; num 값을 누산기 A로 적재
         CPA     100,i       ; A - 100 으로 상태비트 설정
         BRLT    less        ; num < 100 이면 less 라벨로 분기

         STRO    msgGE,d     ; (100 이상) "greater than or equal to 100" 출력
         BR      done        ; 출력 끝났으니 종료 지점으로 점프

less:    STRO    msgLT,d     ; (100 미만) "less than 100" 출력

done:    STOP                ; 프로그램 종료
         .END
```

`CPA`는 A 값을 바꾸지 않고 **상태비트만** 설정하므로, 비교 직후 `BRLT`로 분기를 결정할 수 있습니다.

</RevealAnswer>

## 문제 2 — 숫자 2개의 합과 0 비교

**요구사항**

- 숫자 2개를 입력받습니다.
- 두 수의 **합이 0 이상**이면 `greater than or equal to 0`을 출력합니다.
- 그렇지 않으면 `less than 0`을 출력합니다.

**설계 흐름**

1. `DECI`를 두 번 사용해 `num1`, `num2`를 각각 입력받는다.
2. `LDA num1,d`로 첫 수를 A에 넣고 `ADDA num2,d`로 둘째 수를 더해 **합**을 만든다.
3. `CPA 0,i`로 0과 비교하고, 합이 음수면 `BRLT`로 "less" 라벨로 분기한다.

<RevealAnswer title="문제 2 정답 보기 (클릭하여 펼침)">

```asm
         BR      main        ; 데이터 영역을 건너뛰고 main으로 점프
num1:    .BLOCK  2           ; 첫 번째 입력 숫자
num2:    .BLOCK  2           ; 두 번째 입력 숫자
msgGE:   .ASCII  "greater than or equal to 0\x00"
msgLT:   .ASCII  "less than 0\x00"

main:    DECI    num1,d      ; 첫 번째 숫자 입력
         DECI    num2,d      ; 두 번째 숫자 입력

         LDA     num1,d      ; A = num1
         ADDA    num2,d      ; A = num1 + num2 (합)
         CPA     0,i         ; A - 0 으로 상태비트 설정
         BRLT    less        ; 합 < 0 이면 less 라벨로 분기

         STRO    msgGE,d     ; (0 이상) "greater than or equal to 0" 출력
         BR      done        ; 종료 지점으로 점프

less:    STRO    msgLT,d     ; (0 미만) "less than 0" 출력

done:    STOP                ; 프로그램 종료
         .END
```

`ADDA`로 합을 누산기에 만든 뒤 `CPA 0,i`로 부호를 판별합니다. 합이 음수면 상태비트의 N(음수)이 반영되어 `BRLT`가 분기를 수행합니다.

</RevealAnswer>

## 정리

- **비교 + 분기** 패턴: `LDA`(또는 `ADDA`로 계산) → `CPA`로 상태비트 설정 → `BRLT` 등 조건 분기.
- `BRLT`는 "작을 때만" 점프하므로, **"그렇지 않은 경우(이상)"는 분기하지 않고 그대로 진행**시키는 식으로 if-else를 구성합니다.
- 출력 문자열은 `.ASCII`로 정의하고 **반드시 `\x00`으로 끝**내야 `STRO`가 어디까지 출력할지 알 수 있습니다.
- 데이터 영역이 코드 앞에 오면, 맨 처음 `BR main`으로 **데이터를 건너뛰어** 실행이 변수 자리를 명령어로 오해하지 않도록 합니다.
