이번 글에서는 **Pep/8 어셈블리**로 사용자 입력을 받아 조건에 따라 다른 문자열을 출력하는 두 프로그램을 작성합니다. 핵심은 **비교(`CPA`) → 분기(`BRLT`) → 문자열 출력(`STRO`)**의 흐름을 익히는 것입니다.

## if 문을 어셈블리로 옮길 때 — "거짓일 때 먼저 분기한다"

고급 언어의 `if (조건) { 참동작 } else { 거짓동작 }`을 어셈블리로 옮길 때는, **조건이 거짓일 때 곧바로 분기**해서 참동작을 건너뛰도록 작성하는 것이 정석입니다.

```text
if (num >= 100) {        ; 우리가 원하는 조건(참)
    참동작;
} else {
    거짓동작;
}
```

어셈블리에는 "조건이 참이면 실행"이 따로 없고 **조건 분기 명령(`BRLT` 등)** 뿐입니다. 그래서 위 조건을 그대로 옮기는 대신, **부정(거짓) 조건**으로 바꿔서 분기합니다.

- 원하는 조건: `num >= 100` (참이면 "100 이상" 출력)
- 분기에 쓰는 조건: 그 **반대인 `num < 100`** → `BRLT`로 거짓 처리(else)로 점프

즉 코드 흐름은 이렇게 됩니다.

```text
        CPA   100,i      ; 비교
        BRLT  less       ; (거짓) num < 100 이면 else로 먼저 분기
        ... 참동작 ...     ; 분기하지 않았다면 조건이 참 → 참동작 실행
        BR    done       ; 참동작 후 else를 건너뛰어 종료로
less:   ... 거짓동작 ...   ; 거짓일 때 실행
done:
```

**핵심:** 분기 명령은 **거짓(원하는 조건의 반대)** 을 먼저 검사해 점프시키고, 분기하지 않고 그대로 흘러내려간 경우가 "조건이 참"인 상황이 됩니다. 참동작 끝에는 반드시 `BR`로 거짓동작(else)을 건너뛰어야 둘 다 실행되는 실수를 막을 수 있습니다.

## 문제 1 — 숫자 1개와 0 비교

**요구사항**

- 숫자 1개를 입력받습니다.
- 그 값이 **0 이상**이면 `greater than or equal to 0`을 출력합니다.
- 그렇지 않으면 `less than 0`을 출력합니다.

**설계 흐름**

1. `DECI`로 숫자를 메모리 `num`에 입력받는다.
2. `LDA`로 `num`을 A에 불러온 뒤 `CPA 0,i`로 0과 비교한다.
3. `num < 0`이면 `BRLT`로 "less" 라벨로 분기, 아니면 그대로 진행하여 "0 이상" 메시지를 출력한다.

<RevealAnswer title="문제 1 정답 보기 (클릭하여 펼침)">

```asm
         BR      main        ; 데이터 영역을 건너뛰고 main으로 점프
num:     .BLOCK  2           ; 입력 숫자를 저장할 변수 (2바이트)
great:   .ASCII  "greater than or equal to 0\x00"
less:   .ASCII  "less than 0\x00"

main:    DECI    num,d       ; 숫자 1개를 입력받아 num에 저장
         LDA     num,d       ; num 값을 누산기 A로 적재
         BRLT    else        ; num < 0 이면 less 라벨로 분기
         STRO    great,d     ; (0 이상) "greater than or equal to 0" 출력
         BR      endIf        ; 출력 끝났으니 종료 지점으로 점프
else:    STRO    less,d     ; (0 미만) "less than 0" 출력

endIf:    STOP                ; 프로그램 종료
         .END
```

`CPA`는 A 값을 바꾸지 않고 **상태비트만** 설정하므로, 비교 직후 `BRLT`로 분기를 결정할 수 있습니다. 음수를 입력하면 상태비트 N(음수)이 1이 되어 `BRLT`가 분기합니다.

</RevealAnswer>

## 문제 2 — 숫자 1개와 100 비교

**요구사항**

- 숫자 1개를 입력받습니다.
- 그 값이 **100 이상**이면 `greater than or equal to 100`을 출력합니다.
- 그렇지 않으면 `less than 100`을 출력합니다.

**설계 흐름**

문제 1과 구조가 같고, 비교 대상만 0에서 **100**으로 바뀝니다. `NEGA`로 음수를 만들고 `ADDA 100,i`로 100을 더해 100 이상인지 판별합니다.

<RevealAnswer title="문제 2 정답 보기 (클릭하여 펼침)">

```asm
         BR      main        ; 데이터 영역을 건너뛰고 main으로 점프
num:     .BLOCK  2           ; 입력 숫자를 저장할 변수 (2바이트)
great:   .ASCII  "greater than or equal to 100\x00"
less:   .ASCII  "less than 100\x00"

main:    DECI    num,d       ; 숫자 1개를 입력받아 num에 저장
         LDA     num,d       ; num 값을 누산기 A로 적재
         NEGA                 ; num = -num
         ADDA    0x0064,i     ; num = num + 100
         BRLT    else        ; num < 0 이면 less 라벨로 분기
         STRO    great,d     ; (100 이상) "greater than or equal to 100" 출력
         BR      endIf        ; 출력 끝났으니 종료 지점으로 점프

else:    STRO    less,d     ; (100 미만) "less than 100" 출력

endIf:    STOP                ; 프로그램 종료
         .END
```

비교 대상 값만 `CPA 100,i`로 바꾸면 됩니다. 나머지 분기·출력 구조는 문제 1과 동일합니다.

</RevealAnswer>

## 문제 3 — 숫자 2개의 합과 0 비교

**요구사항**

- 숫자 2개를 입력받습니다.
- 두 수의 **합이 0 이상**이면 `greater than or equal to 0`을 출력합니다.
- 그렇지 않으면 `less than 0`을 출력합니다.

**설계 흐름**

1. `DECI`를 두 번 사용해 `num1`, `num2`를 각각 입력받는다.
2. `LDA num1,d`로 첫 수를 A에 넣고 `ADDA num2,d`로 둘째 수를 더해 **합**을 만든다.
3. `CPA 0,i`로 0과 비교하고, 합이 음수면 `BRLT`로 "less" 라벨로 분기한다.

<RevealAnswer title="문제 3 정답 보기 (클릭하여 펼침)">

```asm
         BR      main        ; 데이터 영역을 건너뛰고 main으로 점프
num1:    .BLOCK  2           ; 첫 번째 입력 숫자
num2:    .BLOCK  2           ; 두 번째 입력 숫자
great:   .ASCII  "greater than or equal to 0\x00"
less:   .ASCII  "less than 0\x00"

main:    DECI    num1,d      ; 첫 번째 숫자 입력
         DECI    num2,d      ; 두 번째 숫자 입력

         LDA     num1,d      ; A = num1
         ADDA    num2,d      ; A = num1 + num2 (합)
         BRLT    else        ; 합 < 0 이면 less 라벨로 분기

         STRO    great,d     ; (0 이상) "greater than or equal to 0" 출력
         BR      endIf        ; 종료 지점으로 점프

else:    STRO    less,d     ; (0 미만) "less than 0" 출력

endIf:    STOP                ; 프로그램 종료
         .END
```

`ADDA`로 합을 누산기에 만든 뒤 `CPA 0,i`로 부호를 판별합니다. 합이 음수면 상태비트의 N(음수)이 반영되어 `BRLT`가 분기를 수행합니다.

</RevealAnswer>
