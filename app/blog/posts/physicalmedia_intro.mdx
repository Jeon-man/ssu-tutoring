피지컬미디어에서는 전기 신호를 **읽고**(Input), 빛·소리·움직임처럼 **반응하게**(Output) 만듭니다. 첫 실습에 앞서 자주 쓰는 회로 기호와 입출력 개념을 정리합니다.

---

## 1. 디지털과 아날로그 입출력

- **DI** (Digital Input): 버튼처럼 `켜짐/꺼짐`, `0/1` 두 상태를 읽습니다.
- **DO** (Digital Output): LED처럼 `켜기/끄기` 두 상태로 출력합니다.
- **AI** (Analog Input): 조도·가변저항처럼 연속적으로 바뀌는 값을 읽습니다.
- **AO** (Analog Output): 밝기·속도처럼 출력의 세기를 조절합니다. 보드에 따라 PWM 신호로 구현하기도 합니다.

> 표기에서 `D`는 Digital, `A`는 Analog를 뜻합니다.

## 2. 기본 수동소자: R, L, C

| 기호 | 소자 | 하는 일 |
| --- | --- | --- |
| R | 저항(Resistor) | 전류를 제한하고 전압을 나눕니다. |
| L | 인덕터(Inductor, 코일) | 자기장에 에너지를 저장하며 전류 변화에 반응합니다. |
| C | 축전기(Capacitor) | 전하를 저장하고 전압 변화에 반응합니다. |

이 세 가지를 합쳐 **RLC 수동소자**(Passive elements)라고 합니다. 외부 전원을 증폭하거나 신호를 만들어 내기보다, 전류와 전압의 흐름을 조절하는 역할을 합니다.

## 3. 반도체와 트랜지스터

반도체는 도체와 부도체의 중간 성질을 가지며, 조건에 따라 전류가 흐르는 정도를 조절할 수 있는 물질입니다. 다이오드와 트랜지스터가 대표적인 **능동소자**(Active elements)입니다.

트랜지스터는 작은 제어 신호로 더 큰 전류의 흐름을 제어할 수 있어 전자 스위치처럼 사용합니다.

- **NPN 트랜지스터**: 보통 부하와 GND 사이에서 전류를 제어하는 **로우사이드 스위치**(low-side switch)에 사용합니다.
- **PNP 트랜지스터**: 보통 VCC와 부하 사이에서 전류를 제어하는 **하이사이드 스위치**(high-side switch)에 사용합니다.

실제 연결 전에는 트랜지스터의 핀 배열(E, B, C)을 데이터시트로 꼭 확인해야 합니다. 제품마다 핀 순서가 다를 수 있습니다.

## 4. 회로도 읽기

**스케매틱 다이어그램**(Schematic Diagram)은 부품의 실제 모양 대신 통일된 기호로 회로 연결을 나타낸 도면입니다. 회로를 설계하거나 다른 사람의 회로를 이해할 때는 이 도면을 기준으로 합니다.

- **VCC**: 회로에 공급하는 양(+) 전원입니다. 실습 보드에서는 `5V`로 쓰는 경우가 많습니다.
- **GND** (Ground): 전류가 돌아오는 기준점입니다. 접지라고도 부릅니다.
- **LED 극성**: LED는 방향이 있는 부품입니다. 긴 다리인 애노드(+)와 짧은 다리인 캐소드(-)를 구분해 연결합니다.

## 시험·실습 예시

> 12번 핀에는 노란 LED, 13번 핀에는 초록 LED를 연결해 각각 켜는 스케매틱 다이어그램을 그려 보세요.

각 LED에는 반드시 **전류 제한 저항**을 직렬로 넣습니다. LED의 순방향 전압은 색상과 제품에 따라 다르며 대략 `1.8~3.3V` 범위입니다. 따라서 5V 전원에 연결할 때는 LED 사양과 목표 전류를 기준으로 저항값을 계산해야 합니다.

```text
디지털 핀 ── 저항 ── LED(+)  LED(-) ── GND
```

먼저 LED 한 개를 켜는 회로를 완성하고, 같은 원리를 12번·13번 핀에 각각 적용해 두 LED를 독립적으로 제어해 보세요.

## 5. 버튼 두 개로 LED 밝기 조절하기

LED는 13번 핀, 증가 버튼은 2번 핀, 감소 버튼은 3번 핀에 연결합니다. 이 예제는 `INPUT` 모드를 사용하므로 각 버튼 입력 핀이 떠 있지 않도록 풀다운 저항을 연결해야 합니다. 버튼을 누르면 입력 핀에 `HIGH`가 들어오도록 연결합니다.

- **BUTTON1 (2번 핀)**: 누르고 있는 동안 밝기가 증가합니다.
- **BUTTON2 (3번 핀)**: 누르고 있는 동안 밝기가 감소합니다.
- 밝기는 20ms마다 한 단계씩 변하며, `0~255` 범위를 순환합니다.

```cpp
const int LED = 13;
const int BUTTON1 = 2;
const int BUTTON2 = 3;

int brightness = 0;

const unsigned long FADE_INTERVAL = 20;

unsigned long lastFadeTime = 0;

void setup()
{
  Serial.begin(9600);
  pinMode(LED, OUTPUT);

  pinMode(BUTTON1, INPUT);
  pinMode(BUTTON2, INPUT);

  Serial.println("=== 시작 ===");
  Serial.print("초기 밝기: ");
  Serial.println(brightness);
}

void loop()
{
  int btn1State = digitalRead(BUTTON1);
  int btn2State = digitalRead(BUTTON2);

  unsigned long currentMillis = millis();

  if (currentMillis - lastFadeTime >= FADE_INTERVAL) {
    if (btn1State == HIGH) {
      brightness++;
      if (brightness > 255) {
        brightness = 0;
        Serial.println("[버튼1] 255 초과 → 0으로 전환");
      }
      Serial.print("[버튼1] 밝기: ");
      Serial.println(brightness);
      lastFadeTime = currentMillis;
    }
    else if (btn2State == HIGH) {
      brightness--;
      if (brightness < 0) {
        brightness = 255;
        Serial.println("[버튼2] 0 미만 → 255로 전환");
      }
      Serial.print("[버튼2] 밝기: ");
      Serial.println(brightness);
      lastFadeTime = currentMillis;
    }
  }

  analogWrite(LED, brightness);
}
```

`millis()`를 사용하므로 `delay()`로 프로그램 전체를 멈추지 않고 20ms마다 밝기를 바꿉니다. 시리얼 모니터를 `9600 baud`로 열면 밝기 변화와 범위 순환을 확인할 수 있습니다.

> 주의: `analogWrite()`로 밝기를 부드럽게 조절하려면 PWM 지원 핀을 사용해야 합니다. 아두이노 Uno에서 13번 핀은 PWM 핀이 아니므로, 실제 페이드 효과를 확인하려면 LED 핀을 `3`, `5`, `6`, `9`, `10`, `11` 중 사용하지 않는 핀으로 변경하세요. LED에는 전류 제한 저항을 직렬로 연결합니다.

## 6. 조도센서로 LED 밝기 제어하기

조도센서를 `A5` 핀에 연결해 주변 밝기를 읽고, 그 값으로 6번 PWM 핀에 연결한 LED의 밝기를 조절합니다. 센서값은 시리얼 모니터에서 확인할 수 있습니다.

```cpp
const int LED = 6;   // PWM 핀
const int LDR = A5;  // 조도센서 연결 핀
int val = 0;
int ledBrightness = 0;

void setup()
{
  Serial.begin(9600);
  pinMode(LED, OUTPUT);
  pinMode(LDR, INPUT);
}

void loop()
{
  val = analogRead(LDR);

  analogWrite(LED, val);

  Serial.print("LDR 값: ");
  Serial.println(val);

  delay(200);
}
```

`analogRead()` 값은 `0~1023`이고, `analogWrite()`의 PWM 밝기값은 `0~255`입니다. LED 밝기가 센서값에 비례하도록 정확히 제어하려면 `map()`으로 범위를 변환해 사용합니다.

```cpp
ledBrightness = map(val, 0, 1023, 0, 255);
analogWrite(LED, ledBrightness);
```
